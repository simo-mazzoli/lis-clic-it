# Documentation

This directory is reserved for project documentation and presentation material.

The repository currently keeps the two project presentations at the repository root:

- `LIS-GenDB_Progetto.pptx`
- `LIS-Synthetic-Gen.pptx`

The executable/data workflow remains separated into:

- `data/` — source material, schemas and linguistic guidelines.
- `scripts/` — retrieval and generation code.
- `output/` — generated dataset artifacts.

No files were moved automatically because presentation paths may be referenced externally.
